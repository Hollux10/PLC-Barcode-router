How to read the log
  • Shows the last 200 protocol messages between this app and the PLC, newest at the top.
  • Colors: blue = received (RX) from the PLC, green = sent (TX) to the PLC, yellow = warning (e.g. wrong offload, PLC disconnected), red = error (e.g. destination 00000 sent because no rule matched).
  • Common messages:
    • 001 — heartbeat between the app and the PLC (keeps the link alive).
    • 042 — barcode scan received from the PLC.
    • 050 — destination response sent back to the PLC (the 5-digit destination).
    • 044 — offload event from the PLC (item sent / confirmed / wrong chute, etc.).
  • Destination 00000 means no matching rule was found for that scan.
